# 용어집

화면, 카톡, 문서에서 같은 것은 같은 말로 부른다. 새 용어나 표기가 필요하면 여기에 먼저 추가하고 쓴다. "쓰지 않는 말"은 예전에 쓰다 바꾼 표현이다. 화면 코드의 문구는 `web/src/copy.ts`에 모아 둔다.

## 메뉴와 화면

| 용어 | 뜻 | 쓰지 않는 말 |
| --- | --- | --- |
| 리포트 | 하단 탭 이름. 화면 제목은 "오늘의 리포트" | 일일 리포트, 대시보드 홈 |
| 공고 | 하단 탭. 안에서 [공고 \| 회사] 전환 | 채용, 잡 |

| 지원 | 하단 탭. 화면 제목은 "지원 현황" | 지원 관리 |
| 관리 | 하단 탭. 설정 화면 모음 | 설정, 어드민 |

## 회사 리서치

| 용어 | 뜻 | 쓰지 않는 말 |
| --- | --- | --- |
| 기본정보 | 공고가 들어온 모든 회사에 자동으로 만드는 리서치 | 빠른 프로필, 기본 정보만 |
| 심층분석 | 관심 회사나 직접 요청한 회사에 만드는 리서치 | 심층 리서치, 리서치 완료 |
| 관심 회사 | ★를 누른 회사 | 즐겨찾기 회사 |
| 모듈 | 리서치를 이루는 단위 | 목차, 섹션 |
| 내 모듈 | 사용자가 추가한 모듈 | 사용자 정의 모듈, 커스텀 모듈 |
| 직무 분야 | 넓은 직무 묶음. 리서치를 함께 쓰는 단위이고 고정 목록에서 고른다. 기본값 AI·데이터 | 직무 프리셋 |
| 직무 유형 | 직무 분야 안의 좁은 구분(예: 데이터 엔지니어, 분석가). 공고 분류·매칭·커리어 지표에 쓴다 | 직무 카테고리 |

모듈 이름(순서대로): 회사 개요, 채용, 사업 구조, 경쟁사, 직무 분야 전략, 직무 조직, 직무 환경·도구, 업계 기초, 현직자 리뷰.

## 사실 표시

| 표시 | 언제 | 화면 |
| --- | --- | --- |
| 확인 | 공시, 회사 발표처럼 공식 출처 | 배지 없음 |
| 보도 | 언론 보도 | 배지 없음, 출처 줄 종류에 "보도" |
| 의견 | 현직자 리뷰 | 점선 배지 "의견" |
| 미확인 | 출처가 1곳뿐이거나 출처끼리 값이 다름 | 회색 배지 "미확인" |
| 찾지 못함 | 찾아봤지만 자료가 없음 | 섹션 맨 아래 회색 줄 "찾지 못함 · 주제" |
| AI 의견 | 매칭 설명, 커리어 제안처럼 AI가 해석한 내용 | 점선 배지 "AI 의견" |

쓰지 않는 말: 추정, 불확실, 자료 없음, 확인 필요(사실 표시로는 쓰지 않음. 프로필의 "확인할 내용"은 별개).

## 표기 형식

| 항목 | 형식 | 예 |
| --- | --- | --- |
| 마감 | D-숫자, 당일은 D-day, 마감일 없으면 상시(채용 시 마감 포함), 지났으면 마감. 정확한 날짜는 상세 화면에서 | D-12, D-day, 상시, 마감 |
| 경력 | "경력" + 범위. 범위는 물결표, 하한만 있으면 "이상", 상한만 있으면 "이하", 연차가 없으면 "연차 무관", 신입만이면 "신입" | 경력 1~10년, 경력 8년 이상, 경력 5년 이하, 연차 무관, 신입 |
| 날짜 | 점으로 구분, 요일 없음. 목록·기준일은 월.일, 연월은 연.월 | 10.12, 2026.03, 2026.10.12 |
| 금액 | 조·억은 소수 한 자리, 만 원은 쉼표 | 00.0조, 0,000억, 0,000만 원 |
| 증감 | 전년 대비. 비율의 증감은 %p | ▲0.0%, ▼0.0%, ▲0.0%p |
| 개수 | 숫자 + 단위 붙여 쓰기 | 공고 3건, 회사 18곳, 리뷰 000건 |
| 출처 줄 | 종류 · 문서 · 날짜 ↗ | 공시 · DART 사업보고서 · 2026.03 ↗ |
| 갱신 주기 | 아래 목록 중 하나 | 매일 |

갱신 주기: 매일, 매월, 분기마다, 반기마다, 새 공시가 나오면, 관련 뉴스가 나오면, 조직 개편 소식이 나오면.

## 버튼과 동작

저장 · 저장하고 다시 매칭 · AI에게 맡기기 · 다시 조사 · + 직접 조사 추가 · + 모듈 추가 · + 추가 · 바꾸기 · 올리기 · 전체 보기 · N건 더 보기 · 출처(스위치) · 처음 값으로 · ○○에서 보기(수집처 공고 페이지로, 예: 직행에서 보기) · 회사 보기 · 로그인 링크 받기 · 다시 시도

## 문장 규칙

- 버튼은 짧은 명사나 동사구로 쓴다(저장, 다시 조사).
- 안내 문장은 해요체로 한 줄만 쓴다(예: "저장하면 지난 공고에도 바로 적용돼요"). 설명이 더 필요하면 ? 아이콘에 넣는다.
- 한 줄짜리 사실은 "날짜 + 무엇이 어떻게"로 쓴다(예: "2026.01 ○○부문 아래 AI데이터팀 신설").
