# 용어집

화면, 알림, 문서에서 같은 것은 같은 말로 부른다. 새 용어나 표기가 필요하면 여기에 먼저 추가하고 쓴다. "쓰지 않는 말"은 예전에 쓰다 바꾼 표현이다. 화면 코드의 문구는 `web/src/copy.ts`에 모아 둔다.

## 사실 표시

| 표시 | 언제 | 화면 |
| --- | --- | --- |
| 확인 | 공시, 회사 발표처럼 공식 출처 | 배지 없음 |
| 보도 | 언론 보도 | 배지 없음, 출처 줄 종류에 "보도" |
| 의견 | 현직자 리뷰 | 점선 배지 "의견" |
| 미확인 | 출처가 1곳뿐이거나 출처끼리 값이 다름 | 회색 배지 "미확인" |
| 찾지 못함 | 찾아봤지만 자료가 없음 | 섹션 맨 아래 회색 줄 "찾지 못함 · 주제" |
| AI 의견 | 매칭 설명, 커리어 제안처럼 AI가 해석한 내용 | 점선 배지 "AI 의견" |

쓰지 않는 말: 추정, 불확실, 자료 없음, 확인 필요(사실 표시로는 쓰지 않음. 프로필의 "확인할 내용"은 별개).

## 매칭

| 용어 | 뜻 | 쓰지 않는 말 |
| --- | --- | --- |
| 점수 | 0~100 정수, 단위 없이 표시 | 매칭률, % |
| 한 줄 판단 | 공고 상세 맨 위의 요약 한 문장 | 총평 |
| 매칭 이유 | 공고 목록에 나오는 한 줄 | 추천 사유 |
| 맞는 점 | 공고 요구와 내 경력이 겹치는 부분 | 강점 |
| 부족한 점 | 공고가 요구하는데 내게 없는 것 | 약점, 갭 |
| 지원 전략 | 이 공고에 앞세울 프로젝트와 나와의 연결 | 어필 포인트, 나와의 연결 |
| 판단 근거 | AI가 공고마다 비교한 항목 · 공고 요구 · 내 근거 · 판정 · 가중치 | 매칭 상세, 평가표 |
| 판정 | 항목마다 충족 · 일부 · 미충족 · 정보 없음 | 결과, 등급 |
| 가중치 | 그 공고에서 항목의 중요도. 공고마다 합 100 | 비중, 배점 |
| 지원 추천 · 고려 · 비추천 | AI가 매긴 공고 전체 판정 | 추천 등급 |
| 내 평가 | 매칭 결과에 내가 남기는 ○ 지원할 만함 · △ 애매 · × 아님과 코멘트. 매칭 기준을 만드는 정답 | 피드백, 라벨 |
| 매칭 지침 | AI가 항목과 가중치를 정하는 기준(`config/match_guide.yaml`). 회차마다 내 평가를 보고 고친다 | 프롬프트 |
| 회차 | 같은 매칭 지침 · 프로필 버전 · 모델로 매긴 한 번 | 라운드, 버전 |
| 기준 샘플 | 회차를 비교하려고 고정한 공고 60건. 내 평가가 정답 | 테스트셋, 골든셋 |
| 평가할 공고 | 화면에서 기준 샘플을 모아 보는 칩(평가한 수/전체) | 라벨링 |
| 공고 정리 | AI가 공고 본문에서 뽑아 둔 매칭 항목(핵심 업무, 필수·우대 스킬, 연수 요건, 직급 등) | 공고 분석, 파싱 |

## 커리어

| 용어 | 뜻 | 쓰지 않는 말 |
| --- | --- | --- |
| 시장 | 커리어 탭 첫 화면. 내 직무의 새 공고·열린 공고, 경력 요구, 직무별 열린 공고, 많이 요구하는 스킬 | 트렌드, 시장 분석 |
| 내 위치 | 커리어 탭 둘째 화면. 포지션 맵, 내 스킬의 수요, 채우면 좋은 것 | 스펙 갭 |
| 성장 계획 | 커리어 탭 셋째 화면. 목표 방향, 다른 방향, 이번 달 할 일, 월간 커리어 리포트 | 로드맵 |
| 내 직무 | 개인 필터에서 고른 직무 유형들 | 관심 직무 |

| 경력 요구 | 열린 공고의 최소 경력 분포: 3년 미만, 3~7년, 7~12년, 12년 이상, 연차 무관 | 연차 분포 |
| 내 연차 | 프로필의 데이터·AI 경력 연수 | 경력 레벨 |
| 포지션 맵 | 직무 유형마다 가로 스킬 적합도, 세로 열린 공고로 찍은 그림. 네 칸은 지금 지원 · 키워서 이동 · 유지 · 비중 줄이기 | 사분면, 매트릭스 |
| 스킬 적합도 | 그 직무 공고가 많이 요구하는 스킬 중 내가 가진 비율(%). 좁은 곳에서는 "적합도". 공고마다 매기는 점수와 다르다 | 적합률, 매칭률 |
| 내 스킬의 수요 | 프로필 스킬마다 내 직무 공고 중 그 스킬을 요구한 공고 수 | 시장 가치 |
| 채우면 좋은 것 | 내 직무 공고가 많이 요구하는데 없거나 써 본 정도인 스킬 | 갭, 약점 |
| 사전에 없음 | 내 스킬 중 스킬 사전에 없어 공고에서 셀 수 없는 것. 0건과 다르다 | 수요 없음 |
| 목표 방향 | 프로필 희망 직무를 직무 유형으로 본 카드. 맞는 점 · 부족한 점은 매칭과 같은 뜻을 그 직무 공고 전체에 쓴 것 | 목표 직무 |
| 다른 방향 | 희망 직무가 아닌 직무 중 수요와 적합도가 함께 높은 것 | 추천 직무 |
| 할 일 | 달마다 적는 학습 · 프로젝트 · 자격증 · 기타 할 일. 화면 제목은 "이번 달 할 일" | 투두, 액션 아이템 |
| 월간 커리어 리포트 | 달마다 만드는 커리어 요약(공고가 한 달 넘게 쌓이면 만든다) | 월간 리포트 |

## 프로필

경력(회사) > 직무 구간 > 프로젝트 3층. 업종 · 직무 · 스킬은 정해진 목록에서 고른다(`config/profile.yaml`, 스킬은 공고에서 나온 목록).

| 칸 | 뜻 | 쓰지 않는 말 |
| --- | --- | --- |
| 경력 | 회사 · 업종 · 기간 · 직급 | 이력 |
| 업종 | 회사가 속한 산업(목록에서 고름) | 산업, 도메인 |
| 직무 구간 | 한 회사 안에서 같은 직무로 일한 기간. 하는 일이 바뀌면 새 칸 | 담당 업무, 비중 |
| 직무별 경력 | 직무 구간 기간으로 계산한 직무마다의 연수 | 직무 연차 |
| 데이터·AI 경력 | 총 경력에서 데이터가 아닌 직무(PI 기획, 영업·MD)를 뺀 연수 | 실무 경력 |

## 지원 단계

| 단계 | 짧은 표기(칩·숫자 박스) | 목록 제목 |

| 관심 | 관심 | 관심 |

| 서류 합격 | 서류 | 서류 합격 |
| 면접 | 면접 | 면접 |
| 결과 | 결과 | 결과(합격·불합격) |

- 지원 상태: 공고마다 고른 지원 단계와 메모·날짜. 고르지 않은 공고는 상태가 없다. 쓰지 않는 말: 북마크, 스크랩
- 다가오는 일정: 지원 현황 맨 위에 모은 관심·지원 공고의 마감과 내가 적은 다음 일정(면접 등). 쓰지 않는 말: 캘린더
- 원문에서 지원하기: 공고 상세의 수집처 원문 열기 버튼(지원은 원문 사이트에서 한다)
- 직접 추가: 수집되지 않았거나 마감된 공고를 지원 현황에 손으로 넣는 것(회사·공고 제목·원문 주소·단계·날짜). 쓰지 않는 말: 수동 등록

## 문장 규칙

- 버튼은 짧은 명사나 동사구로 쓴다(저장, 다시 조사).
- 안내 문장은 해요체로 한 줄만 쓴다(예: "저장하면 지난 공고에도 바로 적용돼요"). 설명이 더 필요하면 ? 아이콘에 넣는다.
- 한 줄짜리 사실은 "날짜 + 무엇이 어떻게"로 쓴다(예: "2026.01 ○○부문 아래 AI데이터팀 신설").
