# 수집 데이터

매일 GitHub Actions(collect)가 공고를 수집해 이 브랜치에 커밋한다. 코드는 main 브랜치에 있다.

| 경로 | 내용 | 바뀌는 방식 |
| --- | --- | --- |
| `state.jsonl` | 공고별 현재 상태: 처음 본 날, 마지막 본 날, 내려간 날, 마감일, 중복 대표, 잡음 여부 | 매일 다시 쓴다 |
| `postings/YYYY/MM/DD.jsonl.gz` | 그날 처음 본 공고의 원본(수집처 응답 포함) | 한 번 쓰면 고치지 않는다 |
| `details/YYYY/MM/DD.jsonl.gz` | 그날 받은 공고 상세(본문) | 한 번 쓰면 고치지 않는다 |
| `companies.json` | 회사별 기업 구분(수집처가 붙인 대기업·공공기관·외국계) | 매일 갱신 |
| `runs/YYYY-MM-DD.json` | 실행 요약(수집처별 건수, 새 공고, 내려간 공고, 오류) | 매일 추가 |

지난 공고는 소급해서 모을 수 없어서, 추이 분석은 이 브랜치가 쌓인 날부터 가능하다.
